# str-inivitations

Premium Digital Invitations & RSVP Tracker website built with Next.js, React, Tailwind CSS, Lucide Icons, and Framer Motion.

## Features
- **21+ Interactive Invitations**: Phone mockup previews for Wedding, Save the Date, Engagement, and Baby Shower websites.
- **Dedicated Unique URLs**: `/invitations/[slug]` for every design with custom OpenGraph metadata.
- **Live QR Code Scanner**: Scan with a phone camera to preview live invitations directly on mobile.
- **Direct WhatsApp Ordering**: Pre-filled messages routed to WhatsApp (`+91 63626 17878`).
- **Interactive Views**: Carousel mode and Grid View with device frame controls.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.
